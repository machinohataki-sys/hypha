# 评分 3 维 (每维 0-100):

## 1. structure_adherence
- 4 slot 齐 + 顺序 (1 句核心 → 3 关键关系 → 1 反例 → 比上次新明白的)
- "1 句核心" 真是 1 句 (≤ 30 字, 不超 2 句)
- "3 关键关系" 真是 3 条且彼此独立 (不重复变体)
- "1 反例" 真是反例 (能挑战 1 句核心), 不是补充
- "比上次新明白" 必须 diff 化 (前后对比, 不是堆砌 "新学到的")

## 2. content_depth
- "1 句核心" 是否真压住本课时的最 load-bearing 概念 (不是边缘细节)
- 3 关键关系是否真 KP 间关系 (推论 / 对立 / 共构), 不是 list
- 反例是否真有杀伤 — 应能给 1 句核心 push back; 软反例 (e.g. "但也有人觉得别的") 扣分
- 新明白部分是否真有 differential ("之前以为 X 现在懂 Y, 因为 Z"), 不是泛泛 "理解更深"
- 80+ 需含 ≥ 1 个具体反例人物/案例 + 1 个明确 differential

## 3. evidence_link
- 1 句核心 → 应能 trace 到本课时 1-2 个 load-bearing KP (kp_id)
- 3 关键关系 → 每条应 link 2 个 KP (kp_id 对)
- 反例 → 应引本课时某 KP 的 critique_of 或 lineage_link 字段
- 新明白 → 应能 cite 上次 lesson (lineage_link 跨课时), 若无上次 lesson 则 cite 用户 vault 旧概念
- 完全无 KP 引用 → evidence_link = 0
