To generate the missing icon.icns:

  Option A — electron-icon-builder (cross-platform, recommended)
    npm install --save-dev electron-icon-builder
    npx electron-icon-builder --input=build/icon-source.svg --output=build --flatten

  Option B — iconutil on macOS (manual)
    1. Build an iconset directory: icon.iconset/
       Required: 16, 16@2x, 32, 32@2x, 128, 128@2x, 256, 256@2x, 512, 512@2x
    2. iconutil -c icns icon.iconset -o build/icon.icns

  Option C — png2icns (Linux/WSL)
    sudo apt install icnsutils
    png2icns build/icon.icns build/icon@512.png build/icon.png

Spec requirements:
  - icon.png   : 1024×1024, sRGB, transparent background
  - icon.ico   : Multi-resolution embedded — 16, 32, 48, 64, 128, 256
  - icon.icns  : Apple iconset — 16, 32, 64, 128, 256, 512, 1024 (×1 and @2x)
