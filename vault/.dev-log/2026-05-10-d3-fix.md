# Dev-log addendum — D3.1 substrate rebuild after MEOW audit

## What MEOW caught

Day 3 (commit 82fe061) shipped 12 philosophy candidate items with `answer_plaintext` (single 80-300 word essay locked under sha256). MEOW substance audit (Opus 4.7 surrogate, codex unavailable, marked NON-SILENT) returned composite 0.625 — below the 0.70 ship gate I'd implicitly committed to. Four critical findings:

1. **Sealed-rubric prose-match collapse**. The sha256 channel required exact-match between candidate response and full-prose model essay (after trim + collapse-whitespace + lowercase). Any synonym, punctuation drift, or clause re-order in a real learner's answer fails. The verification channel was structurally non-functional for the verbose philosophy domain.

2. **Label-cli rated the wrong artifact**. The CLI showed each item's instance + first sixteen characters of the answer hash, but no candidate response. A human rater could only judge "is this rubric well-formed," not "did this candidate response pass." That is rater-agreement on rubric quality, not the inter-rater reliability of evaluator pass/fail decisions that V0.5 claims to gate on.

3. **Seeder silent-skip on edited plaintexts**. Re-running `seed-philosophy-golden.js` after editing a rubric in source skipped the existing JSON instead of regenerating it. No hash-drift detection. Rubric authoring loop was broken.

4. **Three of twelve syllabus anchors were fabrications**. `philosophy-001` cited "MIT OCW 24.00 wk1 — Pre-Socratic substance question," but Yablo's 24.00 begins with personal identity; `philosophy-006` and `philosophy-009` cited Yale OYC PHIL 181, which is Shelly Kagan's "Death" course. The labels were plausible-sounding LLM training-frequency hallucinations. This is exactly the v0.2.1 Galileo failure pattern, which the project memory already names. I repeated it.

## What changed in D3.1

The schema for each golden item now decomposes the rubric into atomic features:

```
answer_features: [
  { id: 'f1', claim: '<atomic claim>', alt_phrasings: ['<phrasing 1>', '<phrasing 2>'], claim_hash, phrasing_hashes },
  ...
]
k_threshold: 2
candidate_responses: [
  { id: 'c1', text: '<example response>', features_hit_truth: ['f1', 'f3'] },
  ...
]
```

Each feature is locked under sha256 at the claim level (preventing silent revision between raters), but matching is no longer prose-equality. A human rater reads a candidate response, marks which feature ids the response hits. Verdict is automatic: pass if `features_hit.length >= k_threshold`, fail otherwise.

Cohen's kappa is now computed over per-candidate per-feature binary cells (each item contributes `candidates × features` cells, three of each in the philosophy seed = nine cells per item, one hundred eight cells across twelve items). Synthetic two-rater smoke on eighteen cells produced κ = 0.778, "substantial" by Landis-Koch, above the 0.70 gate.

The seeder gained `--force-reseal` and `--check-drift` flags. Hash-drift now warns and skips with a non-zero exit; silent skip was removed. Re-running the seed after editing source now requires explicit re-seal.

The fabricated course anchors were replaced with canonical text references — Diels-Kranz fragment numbers, Stephanus pagination, Bekker numbers, Descartes Adam-Tannery volume references, Hume Treatise book/part/section, Kant A/B-edition pagination, Stanford Encyclopedia of Philosophy entries. None of these claim a specific lecture course. They cite the texts that are actually canonical to the question.

## What this records

This is the first MEOW-driven substrate revision in V0.5. It cost approximately one session of work and one commit cycle. The mechanism — daily-ship cadence catching errors before they propagate downstream — is the point. The previous version of D3 would have produced a κ number computed over rubric-quality ratings, not evaluator-decision ratings, and the F1 harness in D4 would have inherited the wrong reliability claim. The audit caught it before the F1 number was published.

The lesson recorded explicitly: I drafted twelve syllabus anchors without cross-checking against the actual courses they cited. The project memory already names this failure mode by name. Creator-blindness held even with the warning written down. External audit is the corrective.
