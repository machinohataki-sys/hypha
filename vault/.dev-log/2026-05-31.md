## E0 retrospective — what worked, what we got wrong

**Worked.** The substrate code path operates end-to-end: SQLite + JSONL dual layer (commits 33eaac7 → 3d814a7), verification channels (1415250 → 0fb827d), 50-item golden set with two domains (8be0623 + d5860df), bilingual zh sidecars unblocking the founder mid-Phase-3 (03c3b42). The mutation-test methodology, born under pressure from the rubric-bug pivot, turned out to be the methodological contribution of E0: an auto-tautology-immune lower-bound on verifier robustness via algorithmic transformations the author could not have rigged. The honest disclosure register held across every public surface: tautology markings, N/A markings, cost-ledger gap, all visible to readers who look.

**Got wrong.** Two structural mistakes. First, the golden set design echoed question vocabulary into feature vocabulary, which let a literate rater keyword-match without engaging the underlying claim. The founder caught this at item 13 of 30, which is late but is not the latest possible catch; the items were authored fast and the design flaw was discoverable in code review before any rater touched them. A constitution rule for future golden item design: features must be testable by reading the candidate alone, without re-reading the question's vocabulary. Second, the four pre-committed escape triggers from V0.5 main plan were written as a decision rule for E0 close, and then bypassed by the pivot without formal retirement. The pivot itself was honest; the retirement step was missed. This is the meta-level mistake that MEOW R3 correctly identified, and the one that turns "PASS" into "CONDITIONAL 14d."

A third item that is not a mistake but is worth recording: the cost-ledger instrumentation was always going to gap somewhere; LLM provider response shapes vary, the placeholder rate card was always going to want re-calibration, and the realistic E0 outcome was "cost-ledger has a hole, queued for E1." The honest path is to disclose the hole at the calibration release surface, which we did, and to make the cost gate pre-committable for E1 via a token-metadata coverage threshold, which the trigger-retirement entry now does.

E0 closes day 28. The substrate is operational. The pre-commitments are pending retirement. The next gate is fourteen days away.
