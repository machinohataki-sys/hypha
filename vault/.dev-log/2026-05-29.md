Two reproduction scripts, `repro.sh` for bash environments and `repro.ps1` for PowerShell, doing the same work on each platform: they install the minimum node dependencies, run the exec-cell verifier across the twenty llm-systems items, run the mutation-test harness across the same twenty items, and write a run log to standard output. The thirty-minute reproduction guarantee is stated as a contract: any reader on a recent macOS, Linux, or Windows install with node and bash or PowerShell available should be able to clone, run `repro.sh` or `repro.ps1`, and see the same F1 number written to their own run.log within thirty minutes wall-clock.

## What the release is, and is not

The calibration release is the dry-run of the E1 week-sixteen specification. The E1 plan calls for a calibration release that is reproducible, frozen at a point in time, and accompanied by a methodology log explaining the numbers and the conditions under which they would be wrong. This first release rehearses the format: a frozen artifact, a reproduction script that works on two shells, a README that names the falsification paths, a dev-log entry that documents what was measured. It rehearses the format on a smaller dataset than E1 will ship — twenty items rather than the eventual full corpus — and against a thinner inter-rater story than E1 will publish. The point of rehearsing it now is to find the rough edges in the format before the dataset and the audience grow.

The point is not the F1 number. The F1 number is a measurement of a verification channel against an algorithmically-generated mutation distribution on author-canonical code. The dev-log at 2026-05-22 names what that number does and does not say. The dev-log at 2026-05-22 also names the three things the E0 substrate did not establish, and the calibration release README mirrors those disclosures rather than burying them.

The point is that the F1 number is reproducible. A reader with bash or PowerShell can run the script, see their own run.log, diff it against the committed one, and either confirm the headline or report a discrepancy. The substrate thesis for E0 says the methodology must be reproducible by a stranger. The calibration release is the operational test of that claim.
