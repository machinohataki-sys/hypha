# Dev-log — V0.5 D4: F1 harness + R1 sidecar + R2 fingerprint

## What MEOW round 2 found

Composite 0.725, above the 0.70 ship gate. All four HALT findings from round one are addressed structurally rather than cosmetically — the feature decomposition replaces full-prose sha256 match, label-cli rates the right artifact, the seeder no longer silently discards edits, and the syllabus anchors are canonical text references that hold up to external lookup. Two leftover findings carried HIGH and MEDIUM severity respectively, and the audit recommended patching them in the same commit as D4 to keep composite at 0.78 rather than 0.725.

The HIGH severity finding is the parallel-rater race condition. A founder running label-cli with `--rater=a` while a contractor runs `--rater=b` on the same item file would silently overwrite each other's writes, because both paths read the JSON before both finished writing. The architectural fix is to move rater work to sidecar files, so rater A and rater B touch different files and never conflict.

The MEDIUM severity finding is that the seeder's drift fingerprint hashed the canonical claim only, not the alt-phrasings. An author editing alt-phrasings in source would not trigger the drift detector that exists for exactly this kind of edit. The fix is to extend the fingerprint to include phrasing hashes alongside claim hashes.

## What D4 ships

The F1 harness now consumes the D3.1 feature-set schema. For each (item, candidate-response) pair, it runs `verifyFeatures` from the sealed-rubric channel — a deterministic substring match over normalized phrasings — and compares the predicted feature set to either author-rated ground truth or human-rater majority. The choice between truth sources is a CLI flag; rater mode is the default and refuses to run unless Cohen's kappa on the topic is above 0.7. Ground mode bypasses the gate and emits a development-mode banner; the F1 it produces is a sanity check of the substring channel itself, not a production benchmark.

The first ground-mode run on the 12 philosophy items reported F1 0.083 across 36 candidate responses. This is not a bug; it is the channel's domain limit. Substring match cannot bridge "monism" and "monistic" — they share a four-character prefix but the longer word ends in `-istic`, not in `-m`. Substring match cannot bridge "falsifiable by observation of substance enduring without water" and "could falsify by finding any matter that endures with zero water." The two phrasings share intent and several keywords but no contiguous substring of meaningful length. Philosophy is a domain where rubrics and learner answers live in the same conceptual space but rarely the same lexical space. The substring channel is suitable for executable artifacts (a code cell either runs and asserts or does not) and for closed-vocabulary domains; it is structurally insufficient for prose. The production verifier for philosophy is a human rater, with sealed sha256 locking the rubric definition only. The F1 number for philosophy will come from rater mode against rater majority, not from the substring channel. This is recorded so a future maintainer does not "fix" the F1 by enriching alt-phrasings into a tangle.

## Sidecar architecture

The main item JSON now stops at the sealed rubric: features, candidate responses, k-threshold, schema version, sealed timestamp. Rater work moves to companion files named `<item-id>.rater-a.json` and `<item-id>.rater-b.json`. The label-cli writes only to its rater's sidecar. The golden-loader merges sidecars into the item shape that downstream consumers (compute-kappa, f1-harness) already know how to read. The race condition is eliminated by file disjointness; two raters cannot collide on the same file because they target different files.

Atomic-rename writes are used inside the sidecar writer to reduce the risk of a partial write being read mid-update. This does not eliminate single-rater self-race (one rater running the same `--rater=a` flag in two terminals), but the explicit concurrency case the V0.5 plan names — founder and contractor in parallel — is now structurally safe.

## R7 fixture

The audit noted that the κ = 0.778 number cited in the previous dev-log lived only in the prose, with no committed script that reproduced it. `app/scripts/test-kappa-smoke.js` is now committed alongside two sidecar fixtures for `philosophy-001` that reproduce the trace deterministically. Running the script reads the synthetic sidecars, computes κ on nine cells (three candidates by three features), and asserts the result lies in the substantial interpretation band.
